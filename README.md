# Resilience Technology · 제품별 투자 피칭

2026년 10월 11일 기준의 네 제품 소개를 GitHub Pages용 정적 웹페이지로 구성했습니다.

| 페이지 | 제품 |
| --- | --- |
| `/camp/` | Rise Camp |
| `/bbung/` | 벙 |
| `/fortune/` | Rise 운명 |
| `/desk/` | Rise Desk / blancblanc |

`npm run build`로 HTML을 다시 만들고 `npm run check`로 생성물과 링크를 점검합니다. 외부 라이브러리나 빌드 서비스는 쓰지 않습니다. `index.html`과 제품별 `index.html`은 저장소에 포함되어 있어 GitHub Pages의 `main / (root)`로 바로 게시할 수 있습니다.

피칭 원본은 각 페이지 하단에 연결했습니다. 제품 구현, 상용화, 실제 사용자 성과를 구분했습니다. 확인되지 않은 시장 규모와 조달액은 숫자로 넣지 않았습니다. 민감한 내부 코드·운영 데이터는 게시하지 않습니다. 이 페이지들은 `noindex`로 검색 색인을 요청하지 않습니다.
